# Countries App - Version 4 — Instructions

## 👋 Welcome!

We are so close to completing our Countries API Application! The only thing left to do is deploy it so it's fully accessible on the internet, then write our README to explain our project to the world 🚀

---

## 🎯 Requirements for Version 4

To complete Version 4, you will...
- Deploy your server/API to Render
- Deploy your frontend to Netlify
- Write a README.md file to explain your project

---

## Remote Architecture

| **Element**    | **Deployment**  | **Description** |
| -------- | --------- | --- |
| UI | Netlify | Deploy frontend through Github. Creates an accessible URL in the browser. 
| Web server | Render | Deploy backend web server through Github. Can respond to HTTP requests from our deployed frontend.
| Database | Neon | Deploy PostgreSQL database to Neon. Connects to Render web server to respond to SQL queries.

---

## 🚀 Roadmap: Step-by-step guide to building Version 4

---

### ⚙️ Set up your `version-4` folder

1. Duplicate your `version-3` folder and rename the copy `version-4`.
2. Deploy your frontend code to Netlify. When configuring your deployment settings, set the Base directory to `version-4/client`, since this folder contains your React code. Use this guide to help you:

   [How to deploy a folder in your Github repo to Netlify](https://docs.google.com/document/d/18jxCUA0bebCyYaIHy8aaKMgOQH4w5-b-iCGDWpV4K4M/edit?tab=t.jnwta4jrhylr#heading=h.scmsi7a6s9yz)

---

### 🎯 Milestone 1: Write your README.md file

The purpose of a README.md file is to explain what your project is all about. It's the first thing someone will see when they view your Github repo. 

1. Create a `README.md` file in the root folder of `countries-app`.
2. [Copy and paste the contents of this template into your `README.md` file.](https://github.com/ac-backend/countries-app-instructions/blob/main/version-4/write-your-README.md)
3. Fill out the template to explain what your project is all about. 
4. Add, commit, and push your work to Github.
   
---

### ⚙️ Deploy your Server/API to Render

Follow this [Render deployment guide](https://github.com/ac-backend/countries-app-instructions/blob/main/version-4/deploy-server-to-render.md) to help you. 

---

### ⚙️ Test everything again... and again! 
1. Test all user flows: submitting the form, saving a country, viewing a country’s view count
2. Check your database to make sure the data is updating correctly

---

### Clean and Comment your code
1. Refactor your backend code to make it clean and modular
2. Comment complex logic to explain how it works

---

### Deploy & Submit
1. Push your code to Github
2. Submit to Canvas!
